# DevOps Project 2026: Building a Highly Available, Scalable Web Application

## Project Description
This repository contains the complete, automated cloud infrastructure design and deployment workflow for the Example University web application. The objective of this project is to migrate a legacy monolithic application layout into a highly available, fault-tolerant, secure, and cost-optimized infrastructure within the Amazon Web Services (AWS) ecosystem. The entire lifecycle is designed and documented so that it can be easily reproduced from scratch by any engineer.
